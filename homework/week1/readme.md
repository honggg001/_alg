# 習題 1：查表法與遞迴效率比較

## 一、作業目的

本次作業使用 Python 實作四種計算 2 的 n 次方的方法，並比較不同演算法的執行效率，了解遞迴與查表法對程式效能的影響。

## 二、程式執行環境

- 程式語言：Python 3
- 開發工具：Visual Studio Code
- 程式檔案：power2n.py
- 測試數值：n = 100（方法 2a 使用 n = 20 進行實測）

## 三、四種方法說明

### 方法 1：直接計算

使用 Python 的 `2 ** n` 直接計算結果。

優點：程式簡單，執行速度快，不需要遞迴。

### 方法 2a：雙重遞迴

利用 `power2n(n-1) + power2n(n-1)` 計算結果。

缺點：每次遞迴都會重複計算相同的問題，時間複雜度為 O(2^n)，執行效率非常差。

### 方法 2b：單次遞迴

使用 `2 * power2n(n-1)` 計算結果。

優點：每次只呼叫一次遞迴，時間複雜度為 O(n)，效率比方法 2a 好很多。

### 方法 3：遞迴加查表法

使用 Python 的 `lru_cache` 儲存已經計算過的結果。

優點：避免重複計算相同的子問題，大幅提升雙重遞迴的效率，時間複雜度降低為 O(n)。

## 四、測試結果

使用 `time.perf_counter()` 測量四種方法的執行時間。

| 方法 | 測試 n | 執行結果 |
|---|---|---|
| 方法 1：直接計算 | 100 | 可快速完成 |
| 方法 2a：雙重遞迴 | 20 | 可完成，但速度較慢 |
| 方法 2b：單次遞迴 | 100 | 可快速完成 |
| 方法 3：遞迴加查表 | 100 | 可快速完成 |

實際執行時間：

- 方法 1：待填入實測秒數
- 方法 2a：待填入實測秒數（n=20）
- 方法 2b：待填入實測秒數
- 方法 3：待填入實測秒數

方法 2a 在 n=100 時需要大量重複遞迴呼叫，預期無法在合理時間內完成，因此改用 n=20 進行測試。

## 五、執行效率分析

從演算法分析可以發現，直接計算的方法最簡單，通常也具有良好的執行效率。

雙重遞迴因為重複計算大量相同問題，效率最差。單次遞迴避免了重複分支，執行效率大幅提升。

加入查表法後，程式可以重複使用已經計算過的結果，因此即使保留雙重遞迴的寫法，也能大幅減少實際計算次數。

方法 1、2b、3 的執行時間非常短，單次測試結果可能受到系統負載影響，不能只根據一次測量就判定絕對快慢。
