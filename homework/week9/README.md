# 搜尋演算法實作與比較

## 一、作業目的

本次作業使用 Python 實作五種搜尋問題，分別運用 DFS、BFS、A* 等搜尋演算法，了解不同搜尋方法的原理、適用情況與時間複雜度。

開發工具為 Visual Studio Code，程式語言為 Python 3。

## 二、程式檔案

| 檔案名稱 | 題目 | 演算法 |
|---|---|---|
| maze_dfs.py | 老鼠走迷宮 | DFS |
| river_bfs.py | 狼羊甘藍菜過河 | BFS |
| eight_queens.py | 八皇后問題 | DFS + 回溯 |
| npc_astar.py | NPC 搜尋玩家 | A* |
| ic_routing.py | IC 電路繞線 | DFS、BFS、A* |

## 三、第 1 題：老鼠走迷宮

### 問題說明

在二維迷宮中，從指定起點出發，尋找一條能夠抵達終點的路徑。

### 使用方法：DFS

深度優先搜尋會沿著一條路徑持續探索，當遇到死路時回到上一個位置，再嘗試其他方向。

程式使用遞迴函式與 visited 集合，避免重複走訪相同位置。

### 複雜度

- 時間複雜度：O(V+E)
- 空間複雜度：O(V)

其中 V 代表節點數，E 代表邊數。

### 結果

程式可以找到從起點到終點的一條可行路徑，並使用 `*` 顯示路線。

DFS 不保證找到最短路徑。

## 四、第 2 題：狼羊甘藍菜過河

### 問題說明

農夫必須將狼、羊、甘藍菜運送到對岸，每次最多只能帶一樣物品。

過程中不能讓狼與羊，或羊與甘藍菜在農夫不在場時單獨留在同一岸。

### 使用方法：BFS

使用四個數字表示農夫、狼、羊、甘藍菜所在的位置。

0 代表左岸，1 代表右岸。

BFS 從初始狀態開始，逐層探索所有合法狀態，直到全部抵達右岸。

### 複雜度

- 時間複雜度：O(V+E)
- 空間複雜度：O(V)

### 結果

BFS 可以找到最少 7 次渡河的解答。

由於 BFS 逐層搜尋，因此在每次渡河成本相同的情況下，可以保證找到最少渡河次數。

## 五、第 3 題：八皇后問題

### 問題說明

在 8×8 棋盤上放置 8 個皇后，要求任意兩個皇后不能位於同一行、同一列或同一對角線。

### 使用方法：DFS + 回溯法

程式從第一行開始，逐行嘗試放置皇后。

每次放置前檢查是否與之前的皇后衝突。

若目前位置合法，就繼續下一行；若沒有合法位置，就回溯到上一行重新選擇。

### 複雜度

- 時間複雜度：可用 O(N! × N) 作為保守上界
- 空間複雜度：搜尋過程 O(N)，不包含儲存所有解答的空間

### 結果

八皇后問題共有 92 種合法排列方式。

程式可以列印所有解答，並使用 Q 表示皇后的位置。

## 六、第 4 題：NPC 搜尋玩家

### 問題說明

在遊戲地圖中，NPC 必須避開障礙物，找到玩家的位置。

### 使用方法：A*

A* 使用以下公式：

f(n) = g(n) + h(n)

其中：

- g(n)：起點到目前節點的實際成本
- h(n)：目前節點到目標的預估成本
- f(n)：總預估成本

本題使用曼哈頓距離作為啟發式函數。

### 複雜度

在一般圖搜尋與優先佇列實作下，常見時間上界為 O((V+E) log V)，空間複雜度為 O(V)。

### 結果

NPC 可以避開地圖中的障礙物，找到通往玩家位置的最短路徑。

## 七、第 5 題：IC 電路繞線

### 問題說明

在二維電路板上，尋找從起點到終點的導線路徑，同時避開不能通過的障礙物。

### 使用方法

本題分別使用 DFS、BFS、A* 三種搜尋演算法。

**DFS：**

優先深入探索一條路徑，遇到死路再回頭，能找到可行路徑，但不保證最短。

**BFS：**

逐層搜尋相鄰節點，在每一步成本相同的情況下，可以找到最短路徑。

**A*：**

利用啟發式函數估計到終點的距離，優先搜尋較有希望的節點。

### 複雜度比較

| 演算法 | 時間複雜度 | 空間複雜度 |
|---|---|---|
| DFS | O(V+E) | O(V) |
| BFS | O(V+E) | O(V) |
| A* | 常見上界 O((V+E) log V) | O(V) |

### 結果比較

DFS 可以找到一條可行路徑，但不一定是最短路徑。

BFS 在每一步成本相同時，可以保證找到最短路徑。

A* 使用適當的啟發式函數時，也能找到最短路徑，且在某些地圖上可以減少搜尋範圍。

實際執行時間與搜尋節點數會受到地圖配置、搜尋順序及電腦效能影響。

## 八、三種搜尋演算法比較

| 比較項目 | DFS | BFS | A* |
|---|---|---|---|
| 搜尋方式 | 深度優先 | 廣度優先 | 啟發式搜尋 |
| 主要資料結構 | Stack / 遞迴 | Queue | Priority Queue |
| 是否保證最短路徑 | 否 | 是，等成本情況 | 是，符合適當條件時 |
| 是否使用啟發式函數 | 否 | 否 | 是 |
| 適用問題 | 迷宮、回溯 | 最短步數、狀態搜尋 | 路徑規劃、遊戲 AI |
