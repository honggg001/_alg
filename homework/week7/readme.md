# 排列組合 C(n,k)：動態規劃與非動態規劃比較

## 一、作業目的

本次作業選擇排列組合 C(n,k) 問題，使用 Python 分別實作一般遞迴法（非動態規劃）與動態規劃法，並比較兩種演算法的原理、時間複雜度、空間複雜度及執行效率。

## 二、問題說明

排列組合 C(n,k) 表示從 n 個不同物品中選取 k 個物品，不考慮排列順序的組合數。

例如，從 5 個物品中選出 2 個：

C(5,2) = 5! / (2! × 3!) = 10

本次作業使用以下遞迴公式：

C(n,k) = C(n-1,k-1) + C(n-1,k)

邊界條件：

C(n,0) = C(n,n) = 1

## 三、非動態規劃：一般遞迴法

檔案名稱：`recursion.py`

### 演算法原理

使用遞迴方式，將組合數問題拆成兩個較小的子問題，直到達到邊界條件。

程式每次都重新計算子問題，沒有儲存已經計算過的結果，因此會產生大量重複運算。

### 複雜度分析

- 時間複雜度：最壞 O(2^n)
- 空間複雜度：O(n)

優點是程式結構簡單，容易理解。

缺點是當 n 增加時，遞迴呼叫次數快速成長，執行效率較差。

## 四、動態規劃：表格法

檔案名稱：`dynamic_programming.py`

### 演算法原理

動態規劃利用二維陣列 dp 儲存已計算過的組合數。

首先建立表格，設定邊界條件，再由小問題逐步計算出大問題的答案。

每個子問題只需要計算一次，因此可以避免一般遞迴法的重複計算。

### 複雜度分析

- 時間複雜度：O(nk)
- 空間複雜度：O(nk)

優點是計算效率較高，適合處理較大的 n 和 k。

缺點是需要額外的記憶體空間儲存表格。

## 五、兩種演算法比較

| 比較項目 | 一般遞迴法 | 動態規劃法 |
|---|---|---|
| 演算法類型 | 非動態規劃 | 動態規劃 |
| 計算方式 | 遞迴展開 | 二維表格 |
| 是否重複計算 | 是 | 否 |
| 時間複雜度 | 最壞 O(2^n) | O(nk) |
| 空間複雜度 | O(n) | O(nk) |
| 執行效率 | 較低 | 較高 |
| 適用情況 | 小規模問題 | 較大規模問題 |

## 六、測試結果

使用以下四組數據測試：

| n | k | C(n,k) |
|---|---|---|
| 10 | 5 | 252 |
| 20 | 10 | 184756 |
| 25 | 12 | 5200300 |
| 30 | 15 | 155117520 |

兩種方法計算出的組合數應該完全相同。

### 執行時間比較

使用 Python 的 `time.perf_counter()` 測量程式執行時間。

實際測試後可填入下表：

| 測試數據 | 一般遞迴時間（秒） | 動態規劃時間（秒） |
|---|---|---|
| C(10,5) | 待填入 | 待填入 |
| C(20,10) | 待填入 | 待填入 |
| C(25,12) | 待填入 | 待填入 |
| C(30,15) | 待填入 | 待填入 |

隨著輸入規模增加，一般遞迴法會產生大量重複計算，而動態規劃可以重複使用已儲存的結果，因此通常具有更好的執行效率。
