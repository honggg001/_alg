# 旅行推銷員問題（TSP）— 五種演算法比較

## 一、專題介紹

本專題使用 Python 實作五種不同的演算法，解決旅行推銷員問題（Traveling Salesman Problem，TSP），並比較不同演算法的求解方式與結果。

旅行推銷員問題的目標是：從指定城市出發，走訪所有城市，每個城市只能拜訪一次，最後返回起點，並使總旅行距離最短。

本專題使用相同的 8 個城市座標進行測試，以確保不同演算法的比較具有一致性。

## 四、測試資料

所有演算法皆使用相同的 8 個城市：

| 城市 | X 座標 | Y 座標 |
|---|---|---|
| A | 2 | 3 |
| B | 5 | 8 |
| C | 9 | 6 |
| D | 12 | 2 |
| E | 8 | 1 |
| F | 4 | 1 |
| G | 1 | 7 |
| H | 7 | 4 |

起點固定為 A，完成所有城市的拜訪後必須返回 A。

城市之間的距離採用歐幾里得距離：

\[
d(i,j)=\sqrt{(x_i-x_j)^2+(y_i-y_j)^2}
\]

總旅行距離為所有相鄰城市距離之和，包含最後返回起點的距離。

## 五、演算法介紹

### 1. 改進法（Improvement Method）

檔案：`01_improvement.py`

使用 2-opt 演算法改善初始旅行路線。

**執行流程：**

1. 建立初始城市拜訪順序。
2. 選擇路線中的一段進行反轉。
3. 計算交換後的總距離。
4. 如果距離縮短，就接受新路線。
5. 重複執行，直到沒有更好的交換方式。

**特點：**

- 容易實作。
- 能有效改善初始路線。
- 不保證一定找到全域最佳解。

### 2. 爬山算法（Hill Climbing）

檔案：`02_hill_climbing.py`

爬山算法是一種局部搜尋演算法，透過不斷尋找更好的鄰近解來改善結果。

**執行流程：**

1. 建立初始路線。
2. 使用 2-opt 產生不同的鄰近路線。
3. 比較所有鄰近路線的總距離。
4. 選擇距離最短的鄰近解。
5. 重複搜尋，直到無法繼續改善。

**特點：**

- 每次選擇目前最好的鄰近解。
- 能逐步改善旅行距離。
- 可能停留在局部最佳解。

### 3. 類比擴大機（Analog Amplifier）

檔案：`03_analog_amplifier.py`

本程式以 Hopfield 類比神經網路模型模擬連續神經元的最佳化過程。

**執行流程：**

1. 建立城市距離矩陣。
2. 初始化神經元狀態。
3. 透過神經元之間的相互作用更新狀態。
4. 逐步降低能量函數。
5. 將神經元輸出轉換成合法旅行路線。
6. 計算總旅行距離。

**特點：**

- 模擬類比神經網路的運作方式。
- 使用能量函數引導搜尋。
- 可能收斂至局部最佳解。
- 需要額外處理神經元輸出，確保路線合法。

註：此處採用 Hopfield 網路作為「類比擴大機」的實作假設，若課堂定義不同，應依指定模型調整。

### 4. 急劇下降法（Steepest Descent）

檔案：`04_steepest_descent.py`

本程式使用連續鬆弛與固定學習率的梯度下降，近似求解 TSP。

**執行流程：**

1. 建立城市距離矩陣。
2. 將城市排列表示為連續矩陣。
3. 建立包含距離與限制條件的目標函數。
4. 計算目標函數的梯度。
5. 沿負梯度方向更新矩陣。
6. 將結果轉換成合法路線並計算距離。

梯度下降更新公式：

\[
X_{k+1}=X_k-\alpha\nabla f(X_k)
\]

其中：

- \(X_k\)：目前的連續矩陣。
- \(\alpha\)：學習率。
- \(\nabla f(X_k)\)：目標函數的梯度。

**特點：**

- 適合連續最佳化問題。
- 可透過梯度調整搜尋方向。
- TSP 為離散問題，因此需要連續鬆弛及解碼。
- 不保證得到全域最佳解。

### 5. 貪婪演算法（Greedy Algorithm）

檔案：`05_greedy.py`

使用最近鄰居法（Nearest Neighbor）建立旅行路線。

**執行流程：**

1. 從 A 城市出發。
2. 尋找距離目前位置最近且尚未拜訪的城市。
3. 移動到該城市。
4. 重複直到所有城市都已拜訪。
5. 最後返回 A 城市。

**特點：**

- 演算法簡單，容易理解。
- 執行速度快。
- 每次只考慮目前最好的選擇。
- 不保證得到最短旅行路線。
